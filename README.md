Just a tiny terminal based monster arena game.

# Build
`./gradlew build`

# Run
`./run.sh`

# Game
First enter your name and select a map size (the smaller, the harder)

Select "Spiel starten".

Move with the arrow-keys.
Shoot with tab-key.

Once all enemies killed a new wave will spawn with one more enemy than last wave.

If you get hit by an enemy, it is game over.
